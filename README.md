# PPT Timer (PPT演示计时器)

一款简洁、透明的桌面计时器工具，专为PPT演示设计。

## 功能特点

- **透明窗口**: 计时器悬浮在屏幕上，不遮挡演示内容
- **始终置顶**: 计时器始终保持在所有窗口最前方
- **可拖拽移动**: 直接拖拽数字即可移动窗口位置
- **鼠标穿透**: 默认允许鼠标穿透，不影响其他操作
- **颜色状态提醒**:
  - 🟢 绿色: 时间充裕 (>50%)
  - 🟡 黄色: 时间过半 (≤50%)
  - 🔴 红色: 时间紧迫 (≤1分钟)
- **声音提醒**: 剩余1分钟时播放提示音
- **超时计时**: 时间结束后继续显示超时时长
- **多显示器支持**: 可快速移动到指定显示器

## 使用方法

### 基本操作

| 操作 | 说明 |
|------|------|
| 右键单击 | 打开设置菜单 |
| 左键拖拽 | 移动窗口位置 |
| 双击关闭全屏提示 | 时间到后点击任意位置关闭提示 |

### 右键菜单功能

- **Start/Pause**: 开始/暂停计时
- **Restart**: 重新开始计时
- **Set Time**: 设置计时时长
  - 预设时长: 1, 2, 5, 10, 15, 20, 30, 45, 60, 90, 120 分钟
  - 自定义时长: 输入任意分钟数
- **Font Size**: 调整字体大小 (20px - 400px)
- **Move to Display**: 移动到指定显示器
- **Volume**: 调整提示音音量 (0% - 100%)
- **Opacity**: 调整窗口透明度 (20% - 100%)
- **Quit**: 退出程序

## 安装与运行

### 直接运行

下载 `PPTTimer.exe` 双击运行即可。

### 从源码构建

```bash
# 进入项目目录
cd extracted

# 安装依赖
npm install

# 运行开发模式
npm start

# 打包为可执行文件
npm run build
```

## 技术栈

- **Electron**: 跨平台桌面应用框架
- **electron-store**: 持久化设置存储

## 设置持久化

应用会自动保存以下设置:
- 上次使用的计时时长
- 字体大小
- 音量设置
- 窗口透明度
